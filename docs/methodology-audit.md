# Methodology audit

The repository was audited against its documentation and current code before the cleanup.

| Area | Verified current behavior | Action |
| --- | --- | --- |
| Selection | Tournament selection, size 3 | README corrected |
| Crossover | Single-point crossover | README corrected; short chromosomes are guarded |
| Fitness | ROUGE-L F plus relevance, coherence, diversity, and length terms | README and implementation made explicit |
| Dataset | `antash420/text-summarization-alpaca-format` in the runner | AG News claim removed |
| Reference usage | Reference summaries are passed into fitness during evolution | Project reframed as reference-guided |
| Embeddings | Historical runner used the first N rows for every document | Runner now requires document-aligned slices |
| Runner path | Entry point is repository-root `run_experiments.py` | Setup instructions corrected |
| Tracked artifacts | Incomplete `.npy`, generated bytecode, and duplicate report files were tracked | Generated/incomplete artifacts removed |

The change is methodological, not metric optimization. Historical outputs remain available in Git history, while new performance claims are intentionally withheld until a complete dataset/embedding manifest and independently reproducible baseline comparison exist.
